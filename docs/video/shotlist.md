# Weather-or-Not demo video: shot list

File `weather-or-not-demo.mp4` (uploaded separately, not committed): 1920x1080, 30 fps, 3:47.7 (227.7 s), H.264 + AAC 48 kHz, loudness normalised to -14 LUFS. Captions are burned in and also provided as `weather-or-not-demo.srt`.

All screen footage is a headless-browser capture of the local stack on one PC on 24 October 2026: the Weather-or-Not UI and agent server (run against a scratch copy of the data directory), the Zetaris gateway, Zetaris Lightning in Docker and Nemotron 3 Nano 4B in Ollama. Nothing was staged in the UI. The FirstEnergy question was typed and run on camera; the run is time-lapsed and the speed is labelled on screen. The American Electric Power restatement conflict is the saved clean run's; the analyst override was signed and posted on camera by the local demo identity, and the override reason was typed for the demo (the label bar says so). Nothing was edited in post apart from the cuts, the camera windows (crops and zooms of the captured page), the speed changes (speed-ups and two slowed static shots, each labelled on screen) and the label bar. Zetaris shots come from the Zetaris UI of the same instance; the login happened before capture and is not shown, and the Data Explorer tree was scrolled so that only the WON_* databases are in frame. A drawn pointer and click ripple mark where each scripted click lands; nothing else was added to the pages.

Data on screen: SEC EDGAR XBRL frames, companyconcept and submissions (US government work, public domain; queried live through Zetaris with a declared User-Agent, never redistributed), NOAA GHCN-Daily (CC0-1.0; a work of the US government; cite NOAA NCEI) and the company_dns SIC list (Apache-2.0 service), all read through Zetaris.

Still shots: title and team cards, the repository's architecture diagram `docs/architecture.png`, an evaluation card (numbers copied from `docs/eval-report.md`, all measured) and a closing card with the data attributions.

Narration: a synthetic text-to-speech voice. No face, no human voice, no music.
